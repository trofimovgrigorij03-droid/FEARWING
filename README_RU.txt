PORT BOT CHILIAD — GITHUB BUILD PACKAGE
=======================================

ЧТО ЭТО
-------
Единый исходный проект для сборки Windows x64 EXE через GitHub Actions.
Это восстановленный прототип, а не обещанная V2: в нём нет подтверждённых
функций FSM/мастера калибровки/F6-F7 из повреждённого архива V2.

КАК СОБРАТЬ EXE ЧЕРЕЗ GITHUB (БЕЗ PYTHON НА СВОЁМ ПК)
-----------------------------------------------------
1. Создай на GitHub новый пустой репозиторий (можно Private).
2. Распакуй этот ZIP на компьютере.
3. Загрузи ВСЕ файлы и папки проекта в корень репозитория.
   Важно: папка .github и файл .github/workflows/build-windows.yml
   должны попасть в репозиторий с тем же путём.
4. Открой вкладку Actions.
5. Выбери workflow "Build Windows EXE".
6. Нажми "Run workflow" → ещё раз "Run workflow".
   Также сборка автоматически запускается при push в main/master.
7. Дождись зелёной галочки у завершённого запуска.
8. Открой запуск workflow, внизу найди Artifacts и скачай
   PORT_BOT_CHILIAD-Windows-x64.
9. Распакуй скачанный ZIP. Запускай PORT_BOT_CHILIAD.exe.
   config.json должен лежать рядом с EXE.

ЕСЛИ ВКЛАДКИ ACTIONS НЕТ
------------------------
Проверь, что папка .github/workflows загружена именно в корень репозитория,
а файл называется build-windows.yml. Затем обнови страницу Actions.

ЛОКАЛЬНАЯ СБОРКА (НЕ ОБЯЗАТЕЛЬНО)
---------------------------------
Нужен Windows и Python 3.10+:
  install.bat
  build.bat
EXE будет в папке dist.

ВАЖНЫЕ ОГРАНИЧЕНИЯ ПРОТОТИПА
----------------------------
- Требуется ручная калибровка config.json под разрешение и интерфейс.
- Навигация упрощённая и ориентируется на экранную метку и её горизонтальное
  смещение; это не надёжная полноценная навигация.
- После подбора/доставки используются фиксированные задержки.
- Успешный цикл определяется по мини-игре; фактическое начисление денег
  интерфейсом не подтверждается.
- Рабочую смену нужно запустить вручную; первая метка должна быть видна.
- pay_per_box — расчётное значение, установи фактическую выплату.

Используй только в собственной тестовой среде/на собственном сервере.
Не используй для обхода античита или автоматизации публичного RP-сервера.
Прототип не является готовым надёжным автономным решением.
